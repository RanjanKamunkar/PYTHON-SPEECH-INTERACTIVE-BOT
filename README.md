# Python Speech Interactive Bot

A simple voice-controlled assistant built using Python. The bot listens for voice commands and performs basic tasks such as opening websites, telling the current time, playing a song, and searching the web.

## Features

- Voice recognition
- Text-to-speech responses
- Open Google and YouTube
- Play songs
- Tell the current time
- Search the web using voice commands

## Technical Requirements

- Python
- SpeechRecognition
- PyAudio
- pyttsx3

## Installation

```bash
git clone https://github.com/RanjanKamunkar/PYTHON-SPEECH-INTERACTIVE-BOT.git
cd PYTHON-SPEECH-INTERACTIVE-BOT
pip install -r requirements.txt
python JARVIS.py
```
